# Агент Unexa: офіційні університети → дані для сайту

Агент знаходить **офіційні** заклади вищої освіти в державному реєстрі, читає їхні офіційні сайти,
за допомогою AI витягує дані про програми й кладе їх у **чернетки** в Supabase.

AI можна вибрати в `agent/.env`:
- `AI_PROVIDER=gemini` — **безкоштовно** (стоїть за замовчуванням). Ключ береться на https://aistudio.google.com.
  Підписка Google AI Pro для цього не потрібна і нічого не змінює.
- `AI_PROVIDER=claude` — платно (потрібен `ANTHROPIC_API_KEY`), краще справляється зі складними сайтами.
На сайт (таблиці `universities` і `specialties`) дані потрапляють лише після вашого схвалення.

Зараз підтримується **Франція** (реєстр Міністерства вищої освіти: 65 університетів, 245 закладів загалом).

```
реєстр Франції → сайт університету → Gemini / Claude → чернетки → ви схвалюєте → сайт Unexa
```

Ця папка не входить у збірку сайту і на Vercel не потрапляє.

## Налаштування (один раз)

1. Відкрийте термінал у папці `agent` і встановіть залежності:
   ```bash
   cd agent
   npm install
   ```
2. Скопіюйте `.env.example` у `.env` і заповніть:
   - `SUPABASE_URL` і `SUPABASE_SERVICE_ROLE_KEY` — Supabase → Project Settings → API
     (саме **service_role**, не anon; цей ключ не можна вставляти у фронтенд);
   - `GEMINI_API_KEY` — безкоштовний ключ з https://aistudio.google.com (Get API key → Create API key).
     Перевірити ключ: `npm run models`.
3. У Supabase → SQL Editor (режим бази даних, не «Logs») виконайте по черзі `sql/001_agent_drafts.sql` (таблиці чернеток)
   і `sql/002_specialty_details.sql` (колонки для фото програми, intake, вартості заявки, розміру групи, кампусу).

## Як користуватися

| Команда | Що робить |
|---|---|
| `npm run models` | перевіряє ключ Gemini і показує доступні моделі |
| `npm run discover` | показує офіційні університети з реєстру (без AI і без бази) |
| `npm run run-agent -- --limit 3 --dry-run` | обробляє 3 університети і зберігає результат лише в `out/` |
| `npm run run-agent -- --only "Sorbonne"` | обробляє університети з цим словом у назві і пише чернетки в Supabase |
| `npm run review` | список чернеток, що чекають перевірки |
| `npm run review -- show <id>` | що саме знайшов агент і з яких сторінок |
| `npm run review -- approve <id>` | публікує на сайт (програми з впевненістю від 0.6) |
| `npm run review -- reject <id>` | відхиляє чернетку |
| `npm run photos -- --dry-run` | показує, які фото знайдено для університетів без фото |
| `npm run photos -- --fix-broken` | додає фото з офіційних сайтів тим, у кого фото немає або воно бите |
| `npm run photos -- --programs` | дає кожній програмі своє фото, щоб картки однієї школи різнились |
| `npm run enrich -- --dry-run` | показує, які порожні поля програм (intake, дедлайни, вартість заявки…) агент заповнить для шкіл, що вже є на сайті |
| `npm run enrich` | заповнює ці порожні поля (нові програми не додає, заповнене не перезаписує); `--only "UdK"` — одна школа |
| `npm run dedupe -- --dry-run` / `npm run dedupe` | знаходить і видаляє дублі програм, переносить збереження користувачів |

Фото програм агент шукає спершу на офіційному сайті школи. Якщо сайт блокує агента, бере вільні фото з
**Wikimedia Commons** (категорія школи через Wikidata). Автор і ліцензія такого фото зберігаються в `source_note`
(рядок `Photo: …`) і показуються на сторінці програми — ліцензії CC цього вимагають.

Корисні параметри `run-agent`: `--all` (також École та інші заклади), `--pages 8` (скільки сторінок читати).

## Що агент заповнює

Поля збігаються з тими, що читає сайт через `src/lib/mapSpecialty.js`:
`name, degree, teaching_language, study_format, tuition_amount, academic_tuition_fee, academic_duration,
academic_study_mode, submission_period, min_language_level, min_cgpa, doc_*, curriculum_summary,
scholarships_text, has_internship, has_certification`.
Значення `degree`, `teaching_language`, `study_format` беруться зі списків фільтрів на головній сторінці.

## Правила, яких агент дотримується

- Бере лише заклади з державного реєстру й читає лише їхні офіційні домени.
- Дотримується `robots.txt`, робить паузу 1,5 с між запитами, не збирає персональних даних.
- Якщо інформації на сайті немає, лишає поле порожнім і нічого не вигадує.
  Кожна програма зберігає посилання на сторінки-джерела та оцінку впевненості.

## Обмеження

- Безкоштовний Gemini має ліміти запитів. Коли ліміт вичерпано, агент сам чекає й пробує ще раз.
  Якщо закінчився денний ліміт, просто запустіть агента наступного дня. Щоб обробити лише ті університети, що не встигли, використайте `--only "назва"`.

- Фото (`cover_image_url`) агент бере з офіційного сайту школи: спершу картинку для соцмереж (og:image), інакше перше велике фото на головній. Логотипи й маленькі картинки пропускає. Якщо фото не знайшлося, на сайті показується заглушка з ініціалами. Права на фото належать школам; для комерційного запуску краще мати власні або ліцензовані фото.
- Якщо у `specialties` колонка зв'язку з університетом називається не `university_id`,
  вкажіть її назву в `.env`: `UNEXA_SPECIALTY_FK=...`.
- Сайти, які повністю будуються JavaScript, можуть прочитатися погано. Їх видно за малою кількістю програм.
